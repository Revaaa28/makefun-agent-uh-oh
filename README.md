# The Agent's Uh-Oh — Wingit

Our entry is the single word **Wingit**: the sound of an agent with no plan, said out loud. It is "wing it" fused into one coined word — a genuine one-word confession of having no plan at all, blurted mid-task, funny on its own with no caption needed, and instantly repeatable.

## Running

```sh
python3 main.py
```

This writes exactly the 6 bytes `Wingit` (no trailing newline) to `/output/entry.txt`, creating `/output` if needed.
